# Ăn Vặt Nhà Uyên

A full-stack web application for a snack store, "Ăn Vặt Nhà Uyên".

## Features
- E-commerce frontend for showcasing and purchasing snacks.
- Staff dashboard for managing products and orders.
- Wishlist functionality to save favorite items.
- Full-stack architecture with a React frontend and Node.js/Express backend.

## Tech Stack
- **Frontend:** React, React Router, Vite
- **Backend:** Node.js, Express
- **Tooling:** ESLint

## Getting Started

### Prerequisites
- Node.js installed

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/tmHieu20-02/an-vat-nha-Uyen.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
